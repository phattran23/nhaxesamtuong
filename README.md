```
sam-tuong-website/

└── assets/images/          ← Thư mục ảnh (6 ảnh công ty)
```

## 🚀 Cách đưa lên GitHub Pages (miễn phí, online trong 5 phút)

### Bước 1: Tạo repository mới
1. Đăng nhập [github.com](https://github.com)
2. Click nút **"+" → "New repository"** ở góc phải trên
3. Đặt tên, ví dụ: `sam-tuong-website`
4. Chọn **Public**
5. Click **"Create repository"**

### Bước 2: Upload file
1. Trong repo mới, click **"uploading an existing file"**
2. Kéo thả cả thư mục giải nén (`index.html` + thư mục `assets`) vào
3. Scroll xuống, click **"Commit changes"**

### Bước 3: Bật GitHub Pages
1. Vào tab **Settings** của repo
2. Menu trái, click **Pages**
3. Mục **"Branch"**: chọn `main`, folder `/ (root)`, click **Save**
4. Chờ 1-2 phút, GitHub sẽ cho link dạng:
   `https://tên-user.github.io/sam-tuong-website/`

Xong! Gửi link đó cho khách hàng.
